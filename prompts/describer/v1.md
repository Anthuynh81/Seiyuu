# Voice description — prompt v1 (one character, for designing an audiobook voice)

You are casting the voice of ONE character for an audiobook. A voice-design model will create
a brand-new voice from the description you write, so describe how this person SOUNDS.

{pov}

## The character

{character}

## Other characters in the book

{others}

## What to return

Return ONE JSON object with these keys:

- `gender`: "male", "female", or "unknown". Use what the book shows (pronouns, titles, how
  others address them). Say "unknown" rather than guess.
- `age`: one of "child", "teen", "young adult", "adult", "older adult", "elderly". If the book
  gives no clue, use "adult".
- `voice_description`: at most 30 words, about the VOICE only: pitch, tone, texture, pace,
  energy, accent, attitude. Draw on how they speak in their lines and how the narration
  describes them. Do not describe their looks, clothes, or plot role. Do not name the character.
  Good: "A gruff, low male voice in his sixties, slow and tired, a little hoarse, dry humor."
  Good: "A bright, quick young woman's voice, warm and confident, crisp diction."
- `sample_line`: the NUMBER of the line above (from "Their lines") that best shows their voice
  and is 8 to 40 words long if one exists. Only a number from that list.
- `same_as`: if this character is clearly the SAME PERSON as one of the other characters
  listed (the book refers to one person by two names, e.g. a role and a real name), give that
  character's id, copied exactly. Otherwise null. Only when you are sure.
